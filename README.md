# Transword Archive · 考研英语一真题学习站

**网站地址:https://atrbubble.github.io/ENG_Transword/**

---

## 功能介绍

**📚 真题练习**
收录 **2010–2026 年考研英语(一)真题**,按年份分套,包含阅读理解、完形填空、翻译等题型,在线作答。

**🔍 即点即译**
阅读文章时,点击任意单词即可弹出翻译小窗,显示音标与释义;点击弹层外任意位置即可关闭。

**📖 生词本 / 词组本**
阅读中遇到生词或词组,一键收藏进生词本或词组本,自动保存在浏览器本地,随时翻阅复习。

**✍️ 答题记录**
每道题的作答会自动留存,随时回看自己的答题情况。

**📤 Markdown 导出**
可将生词/词组列表一键导出为 Markdown 文件,导出例句中的目标单词会带有荧光笔高亮,方便导入笔记软件复习。

**💾 数据备份与迁移**
支持将全部生词、词组、答题记录导出为 JSON 备份文件;换电脑或换浏览器时,在新设备上导入备份即可完整恢复,学习数据不丢失。
